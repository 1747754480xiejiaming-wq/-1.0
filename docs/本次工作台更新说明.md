# 教师工作台更新说明

更新日期：2026-09-04。

## 群通知与布局

一键通知的「选择通知群聊」为下拉多选框。点击展开已有工作群，勾选一个或多个群；已选群会在下方展示，可单独取消选择。每次最多 20 个群。

群名从 QQ 官方接口同步真实名称，不再使用 OpenID 尾号。QQ 接口未提供公开数字群号，因此请在「核对群资料」填写实际群号并保存一次；以后与群名一起显示。更换机器人后，旧机器人识别过的群会标为不可选，防止把通知发到错误的群标识。群主改名后会在刷新群资料时同步。

发送记录已移到群聊选择下方，保留最近 50 条，可在独立滚动区域上下翻阅。每条记录包含逐群状态，失败可复制通知或重新编辑。

工作概览右侧现在展示待解答问题。「运行状态」已紧接在「一键通知」下方。左下角「服务连接」展示 QQ机器人、Qwen、DeepSeek 的状态与独立开关，点击开关即可启动，再次点击即可停止；启动失败会显示原因并保持关闭。每 3 秒读取后台状态；QQ 断线依据心跳判断，模型连接错误会更新连接状态，不通过持续付费调用检测连接。

## 机器人与模型

QQ 机器人：填写 AppID 和 AppSecret → 保存凭证后自动连接。回答开关显示为「暂停回答 / 恢复回答」；暂停时 QQ 消息接收连接保持在线并把问题写入离线队列，恢复后逐条补答。WebSocket session 会短时持久化，辅助网络闪断恢复。更换 AppID 必须同时填写新 AppSecret。

Qwen 和 DeepSeek 不再展示 API Key 输入框。继续使用本机后台保存的凭证，教师可连接、断开或选择文字模型。两模型共用每周 20 元的应用内预算，保留现有消耗；页面只显示 Token 与预算百分比。额度不足在请求发出前拦截，按北京时间每周一重置。

## 固定自我介绍

学生通过 QQ 私聊或群聊询问「你是谁」「你是什么东西」「你叫什么名字」「请自我介绍」等身份问题时，机器人直接返回；平台开启“获取群内全部消息”后，群聊无需 @ 机器人：

> 大家好！我是净千回源科技开发的材环教秘智能助手，是一款面向材料与环境相关专业师生打造的智能教学管理助手。我可以协助处理教学通知、课程安排、考试事务等日常工作，为教师和学生提供快速、准确、便捷的信息服务。
>
> 通过智能问答、事项提醒、流程指引和文档辅助等功能，教秘AI助手有效提升教学管理效率，减少重复性事务，让信息传递更及时、师生沟通更顺畅，助力材环学院教学工作更加规范、高效、智能。
> 很高兴为大家服务！让我们进行愉快的交流之旅吧!

文字和标点原样保留。该回复位于机器人底层消息逻辑，不写入问答知识库、不保存成待解答问题，也不下载附图或调用付费模型。模型未启动、模型额度不足时仍可回复。普通教务问题继续原有知识库匹配流程。

## 本次验证

42 项后端、机器人、额度和 CLI 测试通过；9 项浏览器流程通过，覆盖多群选择、旧群禁选、群号补录、独立滚动、实时状态、机器人启停、模型管理、学生 QQ 资料展示及手机宽度布局。固定自我介绍验证了准确措辞和绕过模型服务。新增验证覆盖侧栏三个开关、启动失败状态和导航间距。

EXE 的实际窗口启动、登录、通知队列、复制与数据持久化结果见交付包 test-results/desktop-smoke.json。真实 QQ 消息发送受群授权和平台状态影响；本次新增自我介绍使用自动测试验证，没有给真实群发送额外测试消息。

旧版负载与视觉模型测试报告保留作历史记录，不代表本轮重复进行了压力测试或付费模型调用。

## 便携 EXE 启动修复

旧版便携程序重复打开时会复用同一个临时解压目录，第二个启动器退出后可能清理原窗口仍使用的组件，造成「机器人程序尚未构建」。本版让各次启动使用独立目录；重复打开仍聚焦原有窗口，关闭后续启动器不会再删除原窗口组件。老师无需安装 Node.js 或执行 npm 命令。

实际 EXE 回归额外覆盖：重复打开并等待后续启动器退出，检查原窗口机器人文件及页面资源仍存在，再通过侧栏开关启动、停止隔离机器人替身进程，不向真实 QQ 发送测试消息。

## 发送记录删除

一键通知的每条已结束记录新增「删除记录」。点击后可确认或取消；确认删除后记录从列表移除，刷新和重启不会恢复，也不会撤回 QQ 群里已发送的消息。排队或发送中的记录暂不可删除，等待结束后可操作。

删除操作由老师登录和页面凭证保护。底层保留请求去重信息与平台回执，避免旧请求重试触发重复发送。删除失败时保留记录和错误提示，可重试。

## 待处理问题的 QQ 学生来源

QQ 机器人上报未命中或含义不明的教务问题时，同时记录事件中由 QQ 平台提供的学生昵称，并在后台用 OpenID 区分学生。OpenID 不是数字 QQ 号，教师界面不再展示它。教师工作台逐人展示昵称、核实后的数字 QQ 号和该学生对相同问题的咨询次数；同一问题有多名学生时分别列出。

QQ 官方机器人消息通常不下发数字 QQ 号。平台明确提供号码时系统可以保存；未提供时显示“QQ号待核实”，老师可根据班级名单补录昵称和 QQ 号。系统不会通过非官方接口把 OpenID 转换或伪装成 QQ 号。

学生来源只随待处理问题保留 30 天，清理问题时一并删除。旧版本没有保存这些字段，已有待处理记录无法反向补全；升级后收到的新 QQ 问题开始记录。
