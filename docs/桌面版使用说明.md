# 校园教务小助手 · 桌面版

## 打开与登录

双击 `release/desktop/校园教务小助手-桌面版-1.0.3.exe`。这是 Windows x64 便携程序，已包含 Electron、前端、后端和 SQLite，不需要安装 Node.js。首次解压加载取决于磁盘性能，可能需要约半分钟至两分钟，启动后显示独立应用窗口。

老师账号默认为 `teacher`，随机口令可从窗口菜单「系统 → 打开老师登录信息」查看。新电脑首次启动会生成自己的账号与数据，不含交付电脑的个人凭证。程序尚未配置商业代码签名证书。界面使用白底水墨主题，标题采用本机宋体，正文和输入框保持清晰易读。

前端与 API 仍分离运行，桌面程序自动启动本机后台并选择空闲端口。关闭全部窗口会停止本程序启动的 API 和机器人进程；群机器人需要电脑和应用保持运行。重复打开会聚焦已有窗口。

## 模型与额度

桌面只保留教师工作台，学生通过 QQ 提问。在「运行状态」分别连接 Qwen、DeepSeek，并手动选择文字模型；图片问题固定用 Qwen。每周共享预算 20 元，页面只显示 Token 和额度百分比，每 3 秒刷新，余额不足会在调用前拒绝。详见《模型与周额度使用说明》。

## 左侧服务开关

「运行状态」紧接「一键通知」下方。左下角 QQ机器人、Qwen、DeepSeek 各有一个开关：点击开启，再点关闭。QQ 使用已保存的 AppID 和 AppSecret；未保存凭证时需先到运行状态填写。模型使用后台已保存的密钥，连接验证仍计入共享周额度。失败会展示原因，开关不会误报成功。

## 机器人与多个学生群

如出现「40034105」，表示 QQ 平台没有授予当前机器人主动群消息权限。请群主在手机 QQ 的该群机器人设置中开启主动发言；仍被拒绝时向 QQ 开放平台核实应用能力，或使用发送记录中的「复制通知」自行转发；不要把机器人已连接当作主动发送已获授权。「重新编辑」只回填内容与失败群，不会自动发送。

1. 登录老师工作台，打开「运行状态」。填写 QQ 开放平台的 AppID 和 AppSecret，点击「保存凭证」，消息接收进程会自动连接。已保存的 AppSecret 不回显；“暂停回答”期间仍接收并排队消息，点击“恢复回答”后逐条补答。
2. 把机器人加入需要通知的学生群。在平台开启“获取群内全部消息”后，群内任意成员发送一条普通消息即可登记群聊；未开启时需 @ 机器人。收到该群事件后，群聊会出现在「一键通知」列表。
3. 点击「选择通知群聊」展开已有群，按 QQ 同步的真实群名勾选；在「核对群资料」补录真实数字群号。停用群与旧机器人未重新识别的群不能被选中。
4. 填写通知标题和正文，查看预览，勾选本次需要通知的 1–20 个群，点击「发送到 N 个群」。页面每 5 秒更新发送记录，逐群显示排队、已发送或失败原因。

群名称来自 QQ 群资料接口，数字群号由老师补录，平台群号不会直接作为可发送标识。已发送表示 QQ 接口接受，不表示学生已读。主动群消息受平台权限和额度限制。

重复提交同一未确认请求会复用队列记录。任务已开始发送后，系统不会自动重发结果不确定的消息；出现「发送结果未确认」时，老师先检查目标群，再决定是否重新编写发送。群被停用后，尚未开始发送的任务会取消，正在进行的外部发送可能已经生效。

## 固定自我介绍

在群里 @ 机器人问「你是谁」「你是什么东西」或「请自我介绍」，会原样返回用户指定的净千回源科技材环教秘智能助手介绍。这条回复在底层实现，不写入知识库、不调用模型；全文见《本次工作台更新说明》。

## 删除发送记录

在「一键通知」的发送记录中点击「删除记录」，核对标题后确认。删除只从工作台移除记录，不撤回群消息；正在排队或发送的记录需结束后再删除。取消或删除失败不会移除记录。

## 数据、升级与备份

默认目录：`%APPDATA%\校园教务小助手`。可用菜单「系统 → 打开本机数据目录」打开。

| 位置 | 内容 |
|---|---|
| `data/campus.db` | FAQ、老师账号、群聊备注、通知记录 |
| `data/qq-credentials.json` | 老师保存的 QQ 凭证 |
| `.local/首次登录.txt` | 本机老师登录信息 |
| `.env` | 端口、数据目录等后端配置，修改后重启 |
| 模型状态目录 / `model-connections.json` | Qwen、DeepSeek 密钥和连接选择 |
| 模型状态目录 / `model-budget.db` | 两个模型共用的周用量账本 |
| `logs/desktop-stack.log` | 本机启动与 API 日志 |

更换 EXE 不会覆盖该目录。备份时先关闭应用，再复制整个用户数据目录；恢复时同样先关闭应用，保留旧目录备份，再放回对应数据。不要把含凭证的数据目录发给学生。

网页版使用工程目录的 `data` 和 `.local`，桌面版使用以上用户目录，知识与通知数据不会实时同步。当前电脑已配置共享的模型状态目录，因此模型连接和周额度在两种入口间共用。当前交付电脑如已迁移数据，迁移记录会列在交付验收中；在其他电脑启动 EXE 会初始化新数据。
