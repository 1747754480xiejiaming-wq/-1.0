# 便携版目录隔离维护

本项目安装的 electron-builder 26.15.3 在 NsisTarget.js 中对 unpackDirName 的布尔分支与类型注释存在差异：true 才不设置 UNPACK_DIR_NAME。本工程据实际代码设置 true，使 portable.nsi 使用每次启动唯一的 PLUGINSDIR/app，避免重复启动退出时清理另一实例文件。

升级打包工具时须检查最终生成脚本与实际两次启动路径，不能只按属性文档调整布尔值。Windows x64 NSIS 启动检查使用 System 插件，会在进入安装段前初始化 PLUGINSDIR。

根因的上游同类问题：[electron-builder issue 7870](https://github.com/electron-userland/electron-builder/issues/7870)。NSIS 插件目录初始化见 [官方说明](https://nsis.sourceforge.io/Reference/InitPluginsDir)。

运行 scripts/test-desktop.mjs 验证重复打开、资源保留、机器人进程启停、窗口关闭和重启数据保留。测试使用独立用户目录，并临时替换该测试实例里的机器人工作进程；不会使用真实 QQ 凭证或向外部群发送消息。
