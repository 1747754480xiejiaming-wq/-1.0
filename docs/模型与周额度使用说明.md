# Qwen、DeepSeek 与共享周额度

更新日期：2026-09-04。

## 连接与选择

登录教师工作台，进入「运行状态」。Qwen 和 DeepSeek 的 API Key 输入框已移除，模型通过本机后台保存的凭证连接。页面保留「连接」与文字模型选择，不显示密钥；连接会进行一次小型付费验证，成功后选为文字模型。两个模型可以同时保持连接，通过「用于文字问题」切换；「断开」停止使用该模型并保留密钥。

Qwen 使用阿里云百炼北京地域 `qwen-vl-plus`；DeepSeek 使用 `deepseek-v4-flash`。本机已保存用户提供的 Qwen 密钥，真实连接和公开问题图片测试成功。本轮升级检查时，本机 DeepSeek 也已由老师保存并连接，现有配置已保留。新的交付包不包含这些密钥，在其他电脑首次使用时由维护人员在后台配置，教师页面不提供密钥输入。

## 图片问题

学生通过 QQ 私聊或群聊提问。平台开启“获取群内全部消息”后，普通群消息无需 @ 机器人。文字问题先匹配知识库，未命中时调用老师选定的文字模型。有图片时始终调用已连接的 Qwen 提取问题，再查找老师维护的标准答案；即使文字模型选择 DeepSeek，也不会把图片送给 DeepSeek。若 Qwen 未连接，会明确提示老师连接，不忽略图片作答。

每条消息最多 3 张 PNG、JPEG 或 WebP，每张不超过 2MB。机器人只从允许的 QQ 图片域名下载附件，需要鉴权的图片由机器人携带 QQ 令牌下载，交给模型的内容只有图片数据；不把 QQ 令牌交给模型。图片不存入知识库或待解答库。

图中问题不清楚、模型判断存在个人敏感资料，或知识库未提供可靠答案时，提示联系老师。模型负责识别和匹配，学生收到的政策答案始终来自当前已启用的知识库。规则无法保证识别所有隐私内容，使用范围为公开教务事项。

## 额度与 Token

两个模型共享每周人民币 20 元的应用内预算，按北京时间每周一 00:00 开启新一周。页面只显示 Token 数和额度消耗百分比，不显示实际消费金额；每 3 秒更新，模型返回用量后记入输入、输出及总 Token，Qwen 图片 Token 包含在输入用量中。连接验证也计入。

每次请求先在 SQLite 事务中预留本次输入与最大输出的预算，再发送到模型。余额不足时，在发送请求前拒绝调用并提示本周超额/余额不足；直接匹配知识库不消耗模型额度，仍然可用。两个模型和多个使用同一额度文件的本机 API 进程共用这道拦截。

用量返回后按输入、输出分别结算。网络超时或服务未返回用量时，保留预占额度，页面显示待核实提示；不会凭空显示 Token，也不会自动重试付费调用。服务重启保留用量；上周记录保留，但不占新一周额度。

计价依据核对于 2026-09-04：[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[阿里云百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)、[Qwen 视觉与图片 Token 说明](https://help.aliyun.com/zh/model-studio/vision)。为避免低估，DeepSeek 按高峰时段、未命中缓存价格预留；Qwen 按北京地域非批量调用价格预留。实际云账单可能因缓存、优惠、免费额度而更低，因此页面百分比是本系统的保守预算占用，并非云平台账单余额。

额度只涵盖经过本系统的模型调用。相同密钥在其他软件、其他电脑的消费不会自动汇总；服务商调价后维护人员应更新后端价格表再使用。本版不提供老师提高预算或清零本周用量的按钮。

## 本机保存与备份

模型状态目录内有 `model-connections.json`（密钥和连接选择）及 `model-budget.db`（周用量）。默认与 API 数据目录一致；可用 `CAMPUS_MODEL_STATE_DIR` 指向固定目录。当前交付电脑的工程版和桌面版共同指向 `%APPDATA%\校园教务小助手\data\model-state`，切换入口不会获得另一份额度。

备份时关闭两个入口，再备份整个模型状态目录；不要删除额度数据库、用旧备份覆盖本周记录，或把含密钥的目录放入公开交付包。知识库数据库的单独备份不包括独立的模型用量数据库。

## 验证范围

真实 Qwen 验证已从合成图片识别「如何申请缓考」，并返回知识库中的标准答案。QQ 私有图片下载、鉴权和转交使用模拟附件测试；真实 QQ 图片事件、平台权限及教师正式知识内容仍需实际业务验收。DeepSeek 路由已通过模拟接口测试；本轮读取到老师保存的已连接状态，没有重复进行付费模型验证。
