## 技能与设计

- taste-skill 的 design-taste-frontend：3 / 2 / 5；精简校园服务、原品牌绿。
- 同包 minimalist-ui 用于管理工作台；正式 Fluent UI 表单、表格、弹窗；Phosphor 图标、Geist 本地字体 + 中文系统字体。
- v2 默认明确排除复杂后台，因此只应用适合的视觉与可访问性原则，不强行套营销页动画或大图。
- nodejs-backend-patterns，wshobson/agents；分层、输入输出校验、鉴权、限流、日志脱敏、注入式服务测试。
- 用单色系、平面布局、少量语义色；按钮 6px、表单 6px、面板 12px；支持明暗主题和减少动效。
