# 校园教务小助手 · 本轮交付验收

日期：2026-09-04。以下内容是当次历史验收记录，不代表当前 GitHub 源码已经重新完成真实外部验收。

## 本轮变化

界面重做为白底、宋体标题、淡墨山水与竹叶边饰；运行状态已删除「问答规则」展示。群通知现在区分平台明确拒绝和网络结果不明，记录成功消息回执，提供「复制通知」「重新编辑」。

桌面和浏览器首页均为教师工作台，已删除学生网页、公开问答接口和学生快捷命令。学生可通过 QQ 私聊或群聊提问；平台开启“获取群内全部消息”时无需 @ 机器人。原有知识维护、待解答处理、多群通知及机器人配置继续保留。

运行状态提供 Qwen、DeepSeek 两张模型卡和独立「连接」按钮，老师可选择文字模型。图片问题固定由 Qwen 识别，再匹配当前知识库；最终政策答案来自数据库，不使用自由生成的答案。

两模型共用每周 20 元预算，按北京时间周一 00:00 重置。发送前通过 SQLite 事务预留用量上限，余额不足会拒绝模型调用并提示超额；页面每 3 秒刷新 Token 和额度百分比，不显示消费金额。重启不清零；当前电脑工程版与桌面版共用模型状态和周额度。

## 使用与交付

双击 `release/desktop/校园教务小助手-桌面版-1.0.3.exe`。默认账号 `teacher`，本机口令从程序菜单「系统 → 打开老师登录信息」查看。本次升级不重置账号。

桌面交付包：`release/校园教务小助手-桌面交付包.zip`。源码包文件名随 `package.json` 版本自动生成。两者提供 SHA256；模型密钥、数据库、QQ 凭证与本机口令不进入发布包。在新电脑首次打开会建立新数据，需要重新填写凭证。

模型使用、计价依据、未知用量处理和备份位置见《模型与周额度使用说明》。百分比按保守价格记账，仅约束经过本系统的调用，不自动汇总同一密钥在其他软件或电脑的消费。

## 尚需实际业务验收

本次保留了老师现有的模型凭证和连接选择，状态以工作台实时显示为准；本轮没有再次发起模型付费测试。QQ 图片鉴权下载使用模拟附件验证，真实 QQ 图片收发仍需业务验收。此前按用户授权向所选学生工作群测试选课通知，QQ 返回 HTTP 400 / 40034105「主动消息失败，无权限」，通知未送达。需要群主开启主动发言并确认平台能力后再发送，程序不能授予平台权限。详情见《群通知修复说明》。
