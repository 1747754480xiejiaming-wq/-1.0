# 辱骂敏感词候选来源说明

软件内置的“辱骂词候选”是人工复核后的多字符候选，仅用于辅助老师构建敏感词库。导入后默认停用，必须由老师检查并启用，避免单字和语境歧义造成误判。

- [COLDataset](https://github.com/thu-coai/COLDataset)：Apache-2.0，用于参考“针对个人/群体攻击”的分类边界；软件不再分发其评论样本。
- [Sensitive-lexicon](https://github.com/konsheng/Sensitive-lexicon)：MIT，用于交叉核对常见写法；仅保留面向他人的辱骂类多字符候选。

未采用无明确许可证的词库，也未采用仅允许非商业用途的数据集。候选词仍可能受上下文影响，正式启用前需要人工复核。
